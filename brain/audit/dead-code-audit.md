## 1. Executive Summary

A comprehensive, read-only audit of the **Yuktivya AI** repository was performed across all 46 tracked source files, dependencies, build configurations, static assets, and simulation engines.

### Key Audit Findings
* **Zero Backend Dead Code / Dead Endpoints:** The application is a client-side Single Page Application (SPA). There are no orphan server routes, Express controllers, or dead backend endpoints.
* **1 Confirmed Dead Component:** `src/components/common/GaugeScore.tsx` (92 lines) is never imported or rendered anywhere.
* **1 Confirmed Dead Stylesheet:** `src/App.css` (185 lines) contains default Vite starter styling that is never imported.
* **4 Confirmed Unused Dependencies:** `clsx` and `tailwind-merge` in `dependencies`, plus `autoprefixer` and `postcss` in `devDependencies`.
* **5 Unreferenced Static Assets:** 3 default Vite template files in `src/assets/` and 2 legacy image files in `public/`.
* **1 Dead Algorithmic Function:** `StatsEngine.calculateLinearSlope` in `src/engine/statsEngine.ts` (L144).
* **1 Abandoned Feature Subsystem:** An i18n translation dictionary in `src/i18n/translations.ts` containing 17 unused translation keys that were never wired to the dashboard views.
* **1 Abandoned Interface:** `ExecutiveReport` in `src/types/index.ts` (L216).

## 3. Confirmed Dead Code

### 1. `GaugeScore` Component
* **Location:** `src/components/common/GaugeScore.tsx` (Lines 1–92)
* **What it does:** Renders an animated SVG circular gauge displaying a score out of 100 with dynamic color thresholds (`emerald`, `amber`, `rose`).
* **Why it appears dead:** Zero imports exist across the entire repository. The dashboard views (`OverviewTab.tsx`) utilize `VerdictCard.tsx` and inline linear progress bars instead.
* **Evidence/Usage trace:** Full-text regex search across `src/` matches only line 12 of `GaugeScore.tsx` itself.
* **Risk:** None.
* **Confidence:** Confirmed Dead (100%).
* **Recommended Action:** Safely delete the file or export it if intended for future use.

### 2. Vite Starter Stylesheet
* **Location:** `src/App.css` (Lines 1–185)
* **What it does:** Default CSS boilerplate generated by `create-vite` (`.counter`, `.hero`, `.framework`, `#next-steps`, `#docs`).
* **Why it appears dead:** `src/main.tsx` only imports `./index.css`. `App.css` is never imported in `App.tsx` or any component.
* **Evidence/Usage trace:** Search for `App.css` across the workspace yields 0 matches.
* **Risk:** None.
* **Confidence:** Confirmed Dead (100%).
* **Recommended Action:** Safely delete `src/App.css`.

### 3. `StatsEngine.calculateLinearSlope` Function
* **Location:** `src/engine/statsEngine.ts` (Lines 144–162)
* **What it does:** Calculates ordinary least squares regression slope for an array of numbers and returns `{ slope, trend: 'increasing' | 'stable' | 'declining' }`.
* **Why it appears dead:** It was likely written for demand or revenue trending, but `demandModel.ts` computes trend direction independently using period deltas.
* **Evidence/Usage trace:** Only declared in `statsEngine.ts`; 0 calls across the entire project.
* **Risk:** None (pure mathematical utility function).
* **Confidence:** Confirmed Dead (100%).
* **Recommended Action:** Either wire it into `demandModel.ts` for rigorous regression slope analysis or remove it.

### 4. `ExecutiveReport` Type Definition
* **Location:** `src/types/index.ts` (Lines 216–244)
* **What it does:** Declares a 28-property TypeScript interface representing an aggregated executive audit document (including `swot` and `actionableRoadmap`).
* **Why it appears dead:** Never referenced by any engine or component. `ReportExporter.tsx` receives direct sub-models via React props rather than building an `ExecutiveReport` object.
* **Evidence/Usage trace:** Search for `ExecutiveReport` matches only line 216 of `types/index.ts`.
* **Risk:** None.
* **Confidence:** Confirmed Dead (100%).
* **Recommended Action:** Remove or retain only as reference for a future unified report store.

## 4. Likely Dead Code

### 1. Unused Component Props in `CompareTab`
* **Location:** `src/components/dashboard/CompareTab.tsx` (Lines 20–22)
* **What it does:** Destructures `currentProductName: _currentProductName` and `currencySymbol: _currencySymbol = '₹'`.
* **Why it appears dead:** Prefixing with `_` suppresses unused variable lint warnings. The component ignores both props and hardcodes comparisons between pre-configured demos (`ALL_DEMOS`) using static `₹` symbols.
* **Evidence/Usage trace:** `App.tsx` passes `currentProductName` and `currencySymbol`, but `CompareTab` does not read them.
* **Risk:** Low.
* **Confidence:** Likely Dead / Stubbed (95%).
* **Recommended Action:** Connect `_currentProductName` so that user-uploaded custom datasets can be selected as "Product A" in the comparison scorecard.
